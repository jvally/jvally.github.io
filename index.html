01 · Jul 2026 – Present

Paranoid Planner

A web-based study planner for NUS students that imports timetables from NUSMods and rewards finished work with gamified productivity points.

  • Hardened JWT authentication: 15-minute access tokens, rotating server-revocable refresh tokens in httpOnly cookies, reuse detection, login rate limiting, and constant-time credential checks.
  • Built a productivity points system that scores task completion by priority, workload, early completion, and daily streaks, recording each award in a PostgreSQL event log with transactional reversals and unit-tested scoring logic.
  • Developed a NUSMods timetable import that validates a user's share link and fetches module details from the NUSMods API, replacing manual module entry.
  • React
